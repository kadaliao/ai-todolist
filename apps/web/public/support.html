Docket 帮助

遇到问题或有建议，请在 GitHub 提交 issue。

怎么快速添加任务？

点右下角的 +，像说话一样输入：“明天下午3点 写周报 #工作 p1”“每周一 例会”。日期、重复、项目、标签和优先级会自动识别并高亮；点一下识别出的部分，就当作普通文字。

怎么在多台设备之间同步？

同步需要你自己的 Docket 服务器（开源，一个 Docker 容器）。部署后为每台设备创建一个令牌，在“设置 → 同步”里填入服务器地址和令牌即可。部署方法见 部署文档。不连接服务器，所有功能也都能在本机使用。

小组件怎么用？（iPhone）

长按主屏幕空白处 → 左上角“编辑” → “添加小组件” → 搜索 Docket。点任务前的圆圈直接完成，点任务打开详情，点 + 快速添加。小组件里勾选的任务会在下次打开 Docket 时正式完成，也可以撤销。

怎么把网页或文字存进 Docket？

在 Safari、备忘录、邮件等应用里点“分享”，选择 Docket。文字会成为任务标题，链接会放进备注；标题里写上“明天 #工作”同样会被识别。

提醒没有响？

请确认系统设置里允许 Docket 发送通知，并在 Docket 的“设置 → 提醒”里打开提醒。带时间的任务默认准时提醒，也可以在任务详情里加提前提醒。

AI 功能怎么开启？

AI 功能由你自己的服务器提供，在服务器上配置任意 OpenAI 兼容的模型即可。AI 生成的任务会先给你预览，确认后才添加，也可以一键撤销。

Docket Support

Found a problem or have an idea? Open an issue on GitHub. See also the privacy policy.

How do I add tasks quickly?

Tap + and type the way you'd say it: “Write the report tomorrow 3pm #Work p1”, “every Monday standup”. Dates, repeats, projects, labels and priority are recognized and highlighted; tap a highlighted part to keep it as plain text.

How do I sync between devices?

Sync uses your own Docket server (open source, a single Docker container). Create a token for each device, then enter the server address and token in Settings → Sync. See the deployment guide. Everything works on the device without a server too.

How do I use the widgets? (iPhone)

Touch and hold the Home Screen → Edit → Add Widget → search for Docket. Tap a circle to complete a task, tap a task to open it, tap + to add one. Tasks checked off in the widget are completed when you next open Docket, and you can undo it there.

How do I save a page or some text to Docket?

Tap Share in Safari, Notes, Mail or any app and choose Docket. The text becomes the task title and the link goes into its notes; “tomorrow #Work” in the title is recognized too.

My reminder didn't go off

Make sure notifications are allowed for Docket in system Settings and that reminders are on in Docket's Settings → Reminders. Tasks with a time remind you on time by default; add earlier reminders in the task details.

How do I turn on AI?

AI is provided by your own server: configure any OpenAI-compatible model there. Tasks drafted by AI are shown for you to review before they're added, and can be undone in one tap.
